# Мой первый проект

Это мой рабочий файл для курса по вайбкодингу.

## Что уже установлено

- **VS Code** — редактор кода.
- **Node.js** — среда выполнения (пригодится в следующих темах).
- **ИИ-ассистент** — подсказывает код прямо в редакторе.

## Что я уже умею

- Открывать проект через **File → Open Folder**.
- Создавать файлы в рабочей папке.
- Открывать терминал внутри VS Code.
